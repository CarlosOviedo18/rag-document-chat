# Recursos del README

Guardar aquí la grabación de la demo como `demo.gif`.

Sugerencia de contenido (unos 30 segundos):

1. El chat vacío con las sugerencias
2. Clic en una sugerencia → indicador de carga → respuesta
3. Desplegar «ver las 5 fuentes» con sus distancias
4. Preguntar algo que NO está en los documentos → admite no saberlo

Los puntos 3 y 4 son los que diferencian este proyecto de un chatbot
cualquiera: demuestran que la recuperación es trazable y que hay control
de alucinaciones.

Herramienta recomendada en Windows: ScreenToGif (gratis, graba directo a
GIF y trae editor para recortar fotogramas). Objetivo: menos de 5 MB.
